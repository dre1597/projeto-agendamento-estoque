# [PAE-000] Recomendações gerais

## Recomendações gerais

- [ ] Deve ser possível escolher entre português, inglês e espanhol para visualização no sistema.
- [ ] Valores monetários, números e datas devem seguir o formato do idioma escolhido.
- [ ] O sistema deve ser capaz de lidar com usuários de diferentes fuso horários.
- [ ] O sistema deve ter um tema claro e um tema escuro.
- [ ] A interface deve ser responsiva, desde TVs até celulares.
- [ ] A interface deve ser acessível (navegação por teclado, contraste e leitor de tela).
- [ ] O acesso a cada funcionalidade deve respeitar o perfil do usuário (administrador, usuário, criador).
- [ ] O sistema deve ter política de senha, limite de tentativas de login e expiração de sessão.
- [ ] Operações concorrentes não podem gerar inconsistência (ex.: overbooking no estoque).
- [ ] Deve ser possível metrificar as queries a banco de dados feitas no sistema.
- [ ] Deve ser possível acesar os logs da api de forma externa.
